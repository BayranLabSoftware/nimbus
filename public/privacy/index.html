Informativa sulla privacy di Bayran Nimbus

Bayran Nimbus è un simulatore che gira dentro il tuo browser: i calcoli avvengono sul tuo dispositivo, non su un nostro server. Un server nostro non esiste. Questa informativa riguarda l'applicazione; le pagine informative del sito hanno un'informativa separata.

Titolare

BayranLab Software. Contatto: bayranlabsoftware@gmail.com.

Dati raccolti: nessuno.

Non chiediamo account, non riceviamo i tuoi dati e non ti profiliamo. Non ci sono pubblicità. Le simulazioni che imposti — luogo, tipo di evento, parametri — restano nel tuo browser e nell'indirizzo della pagina: viaggiano solo se sei tu a copiare quel collegamento e mandarlo a qualcuno.

Statistiche: non attive

Il codice sorgente contiene un modulo facoltativo per statistiche anonime (Plausible), che si accende solo se chi pubblica il sito imposta una variabile apposita. Nella versione pubblicata qui quella variabile non è impostata, quindi il modulo non parte e nessuna richiesta viene inviata. È verificabile: nel pannello di rete del browser non compare alcuna chiamata a statistiche. Se un giorno venisse attivato, questa pagina lo direbbe.

Memoria del browser

L'applicazione salva una preferenza nella memoria locale del browser, per ritrovarla alla visita successiva:

  • i18nextLng — la lingua che hai scelto (italiano o inglese);

È un'impostazione tua, non un identificatore: non dice chi sei e non lascia il tuo dispositivo. La elimini svuotando i dati del sito dalle impostazioni del browser. Cookie non ne vengono installati.

Mappe e terreno: fornitori esterni

Questo è il punto che merita più attenzione. Per disegnare un globo terrestre reale servono mappe, quote del terreno e dati geografici, che non sono ospitati da noi: il tuo browser li scarica direttamente dai fornitori. A seconda di cosa visualizzi possono essere contattati:

  • Amazon Web Services (s3.amazonaws.com) — quote del terreno dal dataset pubblico Terrain Tiles;
  • Esri (elevation3d.arcgis.com, server.arcgisonline.com) — terreno 3D e immagini satellitari;
  • Cesium ion — servizi del motore 3D usato per il globo;
  • OpenFreeMap e WorldPop — mappe di base e dati di popolazione usati per stimare l'esposizione.

Come per qualunque immagine caricata da un altro sito, quei server vedono il tuo indirizzo IP e quali tessere hai richiesto — cioè, in modo indiretto, quale zona del mondo stai guardando. Non inviamo loro nulla di tuo: è il browser che chiede le tessere, e vale la loro informativa. Non possiamo evitarlo senza rinunciare al globo.

Registri del server

L'applicazione è ospitata su GitHub Pages (GitHub, Inc.). Come qualunque server web, per inviarti i file GitHub riceve e conserva per un periodo limitato dati tecnici di collegamento (indirizzo IP, browser, file richiesto), secondo la privacy policy di GitHub.

Minori

L'applicazione non raccoglie dati da alcun utente, compresi i minori.

I tuoi diritti

Non ricevendo noi alcun dato, non ci sono dati nostri su cui esercitare accesso, rettifica o cancellazione: la preferenza sta nel tuo browser e la cancelli tu. Per i dati tecnici trattati da GitHub e dai fornitori di mappe, il riferimento sono le loro informative. Per qualunque domanda puoi scriverci: risponde una persona.

Modifiche

Se questa informativa cambierà, cambierà anche la data in cima. Le versioni precedenti restano nella cronologia pubblica del repository.

English

Bayran Nimbus Privacy Policy

Bayran Nimbus is a simulator that runs inside your browser: the computation happens on your device, not on a server of ours. No such server exists. This notice covers the application; the site's informational pages have a separate notice.

Data controller

BayranLab Software. Contact: bayranlabsoftware@gmail.com.

Data collected: none.

We ask for no account, receive none of your data and do not profile you. There is no advertising. The simulations you set up — place, event type, parameters — stay in your browser and in the page address: they travel only if you copy that link and send it to someone yourself.

Analytics: not active

The source code contains an optional module for anonymous analytics (Plausible), which switches on only if whoever publishes the site sets a dedicated variable. In the version published here that variable is not set, so the module never runs and no request is sent. It is verifiable: no analytics call appears in the browser's network panel. Should it ever be enabled, this page would say so.

Browser storage

The application stores one preference in the browser's local storage, so it can restore it on your next visit:

  • i18nextLng — the language you chose (Italian or English);

It is a setting of yours, not an identifier: it does not say who you are and never leaves your device. You remove it by clearing the site data in your browser settings. No cookies are set.

Maps and terrain: third-party providers

This is the part that deserves the most attention. Drawing a real globe needs maps, terrain elevation and geographic data, which we do not host: your browser downloads them directly from the providers. Depending on what you view, these may be contacted:

  • Amazon Web Services (s3.amazonaws.com) — terrain elevation from the public Terrain Tiles dataset;
  • Esri (elevation3d.arcgis.com, server.arcgisonline.com) — 3D terrain and satellite imagery;
  • Cesium ion — services of the 3D engine used for the globe;
  • OpenFreeMap and WorldPop — base maps and population data used to estimate exposure.

As with any image loaded from another site, those servers see your IP address and which tiles you requested — that is, indirectly, which part of the world you are looking at. We send them nothing of yours: it is the browser that requests the tiles, and their own notices apply. We cannot avoid this without giving up the globe.

Server logs

The application is hosted on GitHub Pages (GitHub, Inc.). Like any web server, to send you the files GitHub receives and keeps for a limited time technical connection data (IP address, browser, requested file), under the GitHub privacy statement.

Children

The application collects no data from any user, including children.

Your rights

Since we receive no data, there is none of ours on which to exercise access, rectification or erasure: the preference lives in your browser and you delete it yourself. For the technical data processed by GitHub and by the map providers, their notices are the reference. For any question you can write to us: a person answers.

Changes

If this notice changes, the date at the top changes too. Previous versions remain in the repository's public history.
